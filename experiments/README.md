# Experiments Directory

Each revenue experiment gets its own subdirectory here.

## Experiment Format

```
experiments/
├── README.md (this file)
├── 001-first-experiment/
│   ├── hypothesis.md    — What are we testing?
│   ├── setup.md         — What was built/deployed?
│   ├── results.md       — What happened?
│   └── earnings.json    — Revenue from this experiment
├── 002-second-experiment/
│   └── ...
```

## Naming Convention
`NNN-short-description/` — numbered sequentially, lowercase with hyphens.
